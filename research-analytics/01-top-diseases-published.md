# Top Diseases Published

Summary

This document lists the top diseases covered by RSJH publications. Use this as the basis for the Rwanda Health Observatory.

Key metrics

- Article count per disease
- Number of unique authors per disease
- Year-over-year growth in disease-related publications
- Downloads and views per disease

Suggested data sources

- Local RSJH article metadata (category, keywords)
- Institution affiliation data
- Google Analytics for view/download counts (when available)

Visualization ideas

- Bar chart of articles by disease
- Time-series line chart showing publication count by year for each top disease
- Choropleth map showing district-level article origins (if location data exists)

Top diseases to track

1. Malaria
2. Tuberculosis
3. HIV/AIDS
4. Maternal health (obstetrics)
5. Cancer
6. Cardiovascular disease
7. Mental health

Notes

Start with articles stored in local storage (for the static site) or the backend API article index when the API is available. Aggregate by disease using keywords and category fields.
