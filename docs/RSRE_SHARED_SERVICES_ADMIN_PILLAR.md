# RSRE Shared Services & Admin Control Center — V16

## Purpose

Provide one operational layer across RSRE without replacing the internal workflow of any pillar.

## User dashboard

The authenticated `/dashboard` is the user's command center. It summarizes:

- Academy progress and credentials
- Research projects
- Active opportunities
- Passport evidence
- Journal activity
- Recent notifications and next actions

The dashboard links into the individual pillar workspaces; it does not duplicate their functionality.

## Shared notifications

RSRE uses the existing journal notification model plus the shared RSRE outbox/service for in-app, email and optional WhatsApp delivery. The dashboard shows unread and recent events so users can maintain momentum.

## Admin Control Center

`/rsre-admin` provides operational oversight for:

- Applications / pillar activation
- Platform settings
- Editable content
- Support tickets
- Notification delivery health
- Administrative audit events

Admins can monitor rather than rewrite protected pillar workflows.

## Protected boundaries

- RSJH editorial workflow remains the source of truth.
- RSJH remains free; support/funding does not buy publication or editorial outcomes.
- Academy, Sandbox and Incubator remain distinct.
- Ethics guidance does not grant statutory ethics approval.
- MedTech AI cannot make editorial or ethics decisions.
- No pillar is silently deleted or replaced by the shared control layer.
