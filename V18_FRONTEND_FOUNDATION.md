# V18 Frontend Foundation

## Purpose
This version begins the product-facing redesign. The backend/pillar contracts are preserved; the work focuses on how people experience RSRE.

## Changes
- Reworked the global RSRE header with clearer information hierarchy, compact navigation, responsive mobile menu, role-aware dashboard CTA and persistent Support RSRE link.
- Added a common visual system for RSRE pages: spacing, panels, navigation, actions, statistics and typography utilities.
- Rebuilt the signed-in user dashboard as a cross-pillar orchestrator rather than a duplicate application.
- Dashboard surfaces momentum: next action, notifications, activity indicators, and entry points to Academy, Discovery, Opportunities, Incubator, Sandbox and Passport.
- Preserved RSJH and Academy contextual navigation while simplifying the global shell.

## UX principle
One RSRE account, one dashboard, distinct workspaces.

Academy = learn/practice.
Sandbox = experiment.
Incubator = execute a real project.
RSJH = free publication.
