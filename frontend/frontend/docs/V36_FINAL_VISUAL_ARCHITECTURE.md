# RSRE V36 Final Visual & Pillar Architecture

- Primary navigation exposes Home, RSJH Journal, Academy, Discovery, Opportunities, Incubator, Passport and About.
- ApplicationShell sub-workspaces reuse RSRE branding, global navigation and shared footer while preserving unique pillar workflows.
- Homepage includes an auto-advancing single-image carousel using the existing public research/health imagery: medical students, healthcare in Rwanda, gorilla/science context and MedTech.
- Homepage includes a CSS marquee-style pillar rail with pause-on-hover and reduced-motion support.
- RSRE Control Center distinguishes global platform services from pillar administration.
- Global Content is explicitly scoped to announcements, banners, FAQs and shared platform notices.
- Academy administration remains separate and edits levels, modules, lessons and assessments.
- Events page does not claim a live event CMS until a real event service is connected.
