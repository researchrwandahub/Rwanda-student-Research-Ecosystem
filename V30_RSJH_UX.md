# V30 — RSJH Journal UX

Protected-core frontend upgrade only.

## Added
- Explicit free-publication messaging for readers and authors.
- Publication metadata presentation: publication date, volume, issue, DOI when provided.
- Clear published/article-type badges.
- Archive context explaining the permanent open record.
- Author manuscript journey reinforces the existing editorial workflow.
- Reviewer confidentiality and decision-boundary guidance.

## Protected
No Article/Review/ReviewAssignment/editorial states, API endpoints, submission flow, revision flow, payment workflow, or publication workflow were removed or replaced.

Protected workflow remains:
Draft → Submit → Editor screening → Reviewer assignment → Peer review → Feedback → Revision → Editorial decision → Publication

## Principle
RSJH is free. RSRE sponsorship is separate and must never influence publication or editorial decisions.
