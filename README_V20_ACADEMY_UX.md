# RSRE V20 — Research Academy UX

This release upgrades the Academy frontend without replacing the existing Academy backend.

## UX model
- Academy: learn, practice, assess, earn credentials.
- Sandbox: experiment with data/tools.
- Incubator: develop real research projects.
- RSJH: protected, free publication workflow.

## Academy additions
- Momentum-focused learning dashboard.
- Progress summary and next-best-action CTA.
- Practical Lab route with submission workspace.
- Lab rubric guidance.
- Guided practice-question generation endpoint derived from the lab rubric.
- Explicit separation between practice questions and assessed questions.
- Certificate visibility across module, level and pathway credentials.

## Validation
- Python syntax compilation passed for modified Academy backend files.
- Full frontend build was not run because `node_modules` is not included in the ZIP.
