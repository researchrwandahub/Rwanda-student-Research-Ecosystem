# V24 — Research Passport UX

## Product intent
The Research Passport is a living research identity, not a CV clone.

## Experience
- Overview: status, evidence score, projects, publications, peer review and credential summary.
- Evidence: chronological RSRE-recorded and researcher-declared evidence.
- Credentials: module, level and pathway certificates from the existing Academy certificate system.
- Profile: interests, methods, skills, competencies, goals and visibility.
- Verification: current RSRE verification code with an explicit non-license disclaimer.

## Boundaries
- Academy is optional; external experience can be declared.
- Declared evidence is never treated as verified automatically.
- Passport summarizes pillar activity; it does not replace pillar workflows.
- RSJH editorial workflow remains authoritative.

## Backend addition
Passport snapshot now includes valid ModuleCertificate records alongside existing LevelCertificate and PathwayCertificate records so module credentials are visible in the Passport.
