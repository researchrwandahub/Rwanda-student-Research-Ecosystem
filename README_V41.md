# RSRE Research Academy V41 - Content Depth Release

This release focuses on the Academy as an RSRE flagship pilot.

## Frontend

- Richer module presentation with learning stages.
- Long-form lesson text rendered in readable sections.
- References shown as supplementary further learning.
- Beginner-first assessment label and instructions.
- Random question selection from the module bank.
- "Try another question set" action without page refresh.

## Backend upgrade

The backend patch is intentionally separate so the existing production/pilot backend and database are not overwritten.

See `ACADEMY_V41_UPGRADE/README.md`.

## Learning principle

Academy assessment begins with foundational understanding, then moves toward application and later professional-level competencies. Academy participation remains optional; the diagnostic is a starting-point recommendation rather than an admissions gate.
