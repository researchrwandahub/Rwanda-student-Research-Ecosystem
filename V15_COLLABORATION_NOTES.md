# V15 — Collaboration Network

Purpose: purposeful research connection, not generic social networking.

Added:
- researcher discovery by field, discipline, institution and interests
- collaboration requests for projects, mentorship, co-authorship, methods support and peer learning
- accept / decline / cancel workflow
- notification when requests are sent or accepted/declined
- optional linking of a request to an existing Research Incubator project owned by the requester
- admin visibility through Django Admin

Boundaries:
- no public social feed
- no automatic authorship
- no editorial influence over RSJH
- no automatic addition to an Incubator project without the project owner's action
- only limited research-relevant profile fields are exposed in discovery
